## About

I am a Software Engineering student at UIT University, Karachi, with a focus on building production-grade systems at the intersection of AI, security, and full stack development. My work spans autonomous multi-agent pipelines, real-time desktop applications, and enterprise-oriented tooling — all designed for reliability and scale.

I approach engineering as a systems discipline: understanding not just how to write code, but how distributed components interact under load, how security boundaries are enforced at the architecture level, and how AI can be embedded meaningfully into operational workflows. I build for environments where correctness is non-negotiable.

My current focus is on **agentic AI systems** — designing pipelines where LLM reasoning drives real-world action with human oversight, grounded in solid infrastructure and observable behaviour.

**Open To:** Software Engineering Internships · AI/ML Engineering Roles · Security Engineering · Open Source Collaboration · Research Opportunities

## Featured Projects

<details>
<summary><b>AI SOC — Autonomous Security Operations Centre</b></summary>

<br/>

An enterprise-grade, autonomous multi-agent Security Operations Centre pipeline designed for **air-gapped deployments**. The system ingests Wazuh security alerts via Apache Kafka, enriches them with threat intelligence from six external sources, generates contextual response playbooks through RAG, and executes them through a self-hosted SOAR platform — with human-in-the-loop oversight at every critical decision boundary.

<br/>

| Attribute | Detail |
|---|---|
| **Stack** | LangGraph 0.2 · LangChain Core 0.3 · FastAPI 0.115 · Electron 28 · React 19 · Vite 7 · Tailwind CSS 4 |
| **Infrastructure** | Wazuh 4.10.2 · Apache Kafka 3.7 (KRaft) · PostgreSQL 16 · Redis 7 · Docker Compose v2 |
| **LLM** | Local vLLM · Meta-Llama-3.3-70B-Instruct-AWQ-INT4 (air-gapped) |
| **Vector Store** | ChromaDB 0.5 · sentence-transformers (all-MiniLM-L6-v2) |
| **Threat Intel** | MISP · VirusTotal · OTX · Shodan · NVD · MITRE ATT&CK · GeoIP2 |
| **Security** | JWT (python-jose) · bcrypt · air-gapped network architecture |
| **Monitoring** | Prometheus · Grafana |
| **SOAR** | Shuffle (self-hosted) |
| **Repository** | [Hamza-Ahmed-S/AI-SOC](https://github.com/Hamza-Ahmed-S) |

<br/>

This project addresses a real gap in enterprise security: the operational cost of triaging high-volume alert streams without qualified analyst bandwidth. By combining local LLM inference with structured agentic reasoning and MITRE ATT&CK context, the pipeline reduces mean-time-to-response for classified incidents and generates audit-ready playbooks. Air-gapped design ensures the system is viable in regulated environments where external API calls are prohibited.

</details>

<details>
<summary><b>YouTube Music Jam — Desktop Collaborative Player</b></summary>

<br/>

A desktop application that extends YouTube Music with a real-time collaborative "Jam" feature, enabling multiple users to share and co-control a listening session — replicating Spotify Jam's social listening experience on top of YouTube Music's catalogue.

<br/>

| Attribute | Detail |
|---|---|
| **Stack** | JavaScript · Electron |
| **Scale** | Multi-user session, peer-to-peer sync |
| **Performance** | Native desktop performance via Electron shell |
| **Security** | Local session management, no credential storage |
| **Impact** | Brings collaborative listening to the world's largest music catalogue |
| **Repository** | [Hamza-Ahmed-S/Youtube-Music-Jam](https://github.com/Hamza-Ahmed-S) |

<br/>

YouTube Music lacks a native group listening feature despite Spotify's Jam being one of its most-used social functions. This project fills that gap by building session synchronisation and queue management directly into a desktop wrapper, giving users collaborative control over playback without leaving the YouTube Music ecosystem.

</details>
